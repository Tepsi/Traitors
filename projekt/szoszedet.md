# Szószedet (egységes szóhasználat a fejezetekben)

Nyilvános, spoilert nem tartalmaz. Az átolvasásnál (CLAUDE.md, 3. lépés) Grep-pel keresd a rossz alakokat. Új szabályszó bevezetésekor vedd fel ide.

| Fogalom | Használt szó | Kerülendő |
|---|---|---|
| Az árulók új taggal bővülnek | *meghívás*, *meghívott*, „meghívunk valakit", „új tagot hívnak maguk közé" | „behívás", „behív" (Zoli döntése, 2026-11-09; a 6–7. fejezet is így írja) |
| Ha már csak egy áruló maradt | *zsarolás*, *megzsarolt* | „kényszertoborzás" |
| Az árulók listája a Kerekasztal szűkítéséhez | *halállista*, *listás*, „listát ír" | „feketelista", „gyilkoslista" |
| A kiesés | *elfelejtés*, „elfelejtetett" (a névtábla betűi lekopnak) | „meghalt", „megölték" a játék szavaival |
| Az árulók éjszakai megbeszélése | *konklávé* („az első konklávé", „a nyolcadik konklávé") | „gyűlés", „találkozó" |
| Az ajtó, amelyen a kiesett távozik | *a Kapu* („a Kapun át") | „a kijárat", „a kapu" kisbetűvel |
| A nappali szavazás | *Kerekasztal* (nagy K) | „szavazás" önállóan csak általános értelemben |
| A reggeli terítéke | *teríték* | „prakker" |
| A Játékmester | *Játékmester*, Szerafin Barnabás | a tévéműsor neve és logója tilos |
| Díj | *fődíj* (nulláról indul, a közös játékokon nő) | „jackpot" |
| A kiesett búcsúja | *búcsú*: előbb beszél, a szerep kimondása a csattanó, utána legfeljebb elköszön | |
| A lefekvés jele | *gongszó*, *gong* | „csengő" |
| Védelem az éjszaka ellen | *pajzs* (a Kerekasztalnál nem véd) | „vért" |
