# Árulók – Halálos kastély

Magyar nyelvű, fejezetekben megjelenő fikciós sorozat egy halálos társasjátékról.

A Holdvári-kastélyban huszonkét régen elhunyt, közismert híresség játssza a játékot, amelyet a kastély titokzatos Játékmestere, Szerafin Barnabás vezet. Köztük árulók rejtőznek: minden éjszaka kiválasztanak egy ártatlant, akit reggelre elfelejt a világ. Nappal a vendégek nyomoznak, gyanakodnak, és a Kerekasztalnál szavaznak.

A hangulat komor és fenyegető, a humor a humoristáké: Kabos, Latabár, Hofi, de Funès, Armstrong és Mercury viccel, a Játékmester soha.
